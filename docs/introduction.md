# RotyPHP

RotyPHP é um micro-ORM simples e eficiente, construído em PHP para SQLite usando PDO. O foco é fornecer uma sintaxe limpa e fluente, abstraindo queries SQL para operações rotineiras.

O projeto é 100% open-source e conta com:

- Models
- Migrations
- Query Builders

O RotyPHP funciona em qualquer projeto com o PHP 8+, seja sistema legado ou moderno, você terá o mesmo acesso ao banco de dados.

> Atualmente, o projeto está em versão de desenvolvimento, não é recomendado o uso para projetos grandes.

Visite nosso [Packagist](https://packagist.org/packages/silvaleal/rotyphp) ou nosso [Github](https://github.com/silvaleal/rotyphp) para informações avançadas ou fundamentais.

## Por que RotyPHP?

Além de reduzir o código que você irá precisar escrever, o RotyPHP tem a missão de reduzir o trabalho seja para criar ou editar tabelas, ou criar, consultar ou editar dados já registrados.

Oferecemos um cenário altamente customizavél, onde qualquer pessoa pode customizar ou criar um ORM, utilizando nosso QueryBuilder.
