# Instalação

Para aqueles que queiram criar seu próprio ORM, utilizando nosso Builder Query, oferemos a nossa biblioteca separada, onde pode ser instalada pelo composer.

> Caso você só queira utilizar o RotyPHP, não será preciso instalar, já que nosso builder já vem em nosso ORM.

## Requisitos

- PHP 8.0+
- Composer

## Instalar via Composer

No seu projeto, execute:

```bash
composer require silvaleal/rotyquery
```
